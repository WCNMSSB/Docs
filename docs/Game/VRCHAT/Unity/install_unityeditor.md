## 下载和安装包管理器(ALCOM/VCC)

ALCOM是一个开源的第三方包管理器，非常好用

支持简体中文等多种语言，体积小，上手快,支持多平台

[点击这里前往ALCOM下载页](https://vrc-get.anatawa12.com/zh-hans/alcom/)

VRChat Creator Companion（VCC）是VRC官方推出的包管理器

因使用麻烦，没有简体中文所以不推荐

[点击这里前往vcc下载页](https://vrchat.com/home/download)

## 下载和安装Unity Hub

Unity Editor需要Unity Hub来获取许可（好像是必须的）

如果你想通过Unity Hub来安装Unity Editor则需要国际版（不然可能无法下载/下载到国内特供C1版本）

下载安装登录建议全程挂魔法（要不然会下Unity Editor会下到国内特供C1版本）

（国内版超级超级超级不推荐使用！！！！）
