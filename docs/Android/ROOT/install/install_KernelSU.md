## 前提和要求

你需要一台已经解锁了`BootLoader`的设备(Android系统)，第二台设备（强烈建议/对于大部分设备必须）（建议是电脑），一根用来连接两个设备的线

## 明确类型

KernelSU有3种模式

            LKM模式
            GKI模式
            越狱模式

## 检查支持

打开你要刷的设备的设置中的设备详情页

翻一翻找到内核版本

内核版本大于5.10的可以直接刷写

小于的则可能需要编译
