# Quest上手激活教程

本教程会尝试教会你激活你的Quest

必备:一台手机、一个可以正常使用的邮箱、你要激活的quest、魔法(梯子)、电脑(可选且建议)

本教程不教学关于如何使用魔法

## 下载Meta Horizon

Meta Horizon是Quest配套的app，是正常激活的必备软件

如果你还没有Meta Horizon可以[点击这里下载](https://pan.baidu.com/s/1M6znZqu1SwE2bU0PzDD74g?pwd=WBDS )

下载完成后使用[MT管理器](https://mt2.cn/)安装

## 注册Meta账号

Meta有一种推荐制度:向朋友推荐quest让他通过你的推荐连接注册你可以使用我的链接注册

[点这里打开](https://www.meta.com/referrals/link/WCNMSSB)

注意:需要梯子且建议是美国

点进去后点击Sgin up or log into Meta account 或者注册登录选项

然后你会来到注册或创建页面

有三个选项：

          通过Facebook

          通过Instagram

          使用电话号码或者邮箱

建议用电话号码或者邮箱注册

建议使用GmailH或者Outlook(QQ和163也行但是不建议)

然后可能需要填写你的姓名和生日

然后填写你的密码

然后就需要确认你的信息了

确认完成后就需要接收验证码了

去你的邮箱查看然后填写

然后创建你的Meta Horizon 档案

填写你的名字用户名

然后选择可见范围 建议私密Private

然后同意并继续

再继续

应该就行了

## 开箱你的Meta Quest

记得一定要录开箱视频！！！！！！！！！！

拿到快递先检查快递盒外观并拍摄四周

然后打开它拿出Quest的盒子也拍摄四周

然后验机器型号和参数 官翻机的封条会有  再生机  的字样

然后录视频撕掉封条打开盒子并拿出机器 然后检查配件和机器外观

然后不要撕掉镜头膜

检查屏幕以及机器状态

没问题直接开机（不要撕掉镜头膜）

仔细检查屏幕

确认无问题后准备激活

## 准备激活

#### 准备工作

打开你的手机

下载Meta Horizon

挂上魔法后手机打开Meta Horizon并登录你的账号

然后点击右下角

点击上面配对新设备

选择你的机型

### 使用手机激活

#### 使用手机VPN

##### 方法1 Proxy Server（无需root）

安装并打开Proxy Server

点击右上角Add

选择Proxy Server

Server name 随便填 建议纯英文

然后点击get random port

然后直接返回

点击yes 保存

带上你的Quest

跟随教程调整至舒适后选择语言

然后就到了连接网络页面

选择你的网络

点击 高级 

代理选择 手动

代理主机名填写手机ip

端口看Proxy Server里的

填完后点确认

然后填密码 点连接

##### 使用Netproxy等（Root）

打开Netproxy并给予root权限

在节点选择正确订阅

点击设置——代理设置

打开网络开关栏目中的开关（取决于你手机的联网方式）

代理ipv6建议选代理ipv6

找到网络协议一栏

勾选所有（代理usb共享流量非必须，其他必须）

然后打开主页的开关

打开手机热点

带上你的Quest

跟随教程调整至舒适后选择语言

然后就到了连接网络页面

选择你的热点并连接

等待设备更新固件

重启以后应该显示配对码了

然后看手机

填入配对码

然后跟着走

手机端完成后看头显

跟着走（教程不建议跳过）
